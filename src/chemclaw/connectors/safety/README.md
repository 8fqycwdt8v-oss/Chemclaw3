# `connectors/safety` — hazard screening, and the judgment for acting on a flag

Two halves that deliberately did not move together. The **screen** is `Chemclaw3-mcp`'s — an
ordinary MCP server with the hazard table baked into its image — so this bundle declares an
`endpoint:` and runs no `server/` of its own. The **judgment** stayed: `skills/` holds the
`safety-screening` `SKILL.md`, because judgment is architecture layer 3 and does not follow the
engine.

It is no longer a gate. `D-2026-08-15-safety-is-a-tool-not-a-gate` retired the `kg-validate` hazard
gate, which is also what ended `science/safety`'s claim to be infrastructure — a screen a model
calls is a tool like any other.

## The hand-driven F6 turn

`make live-storm` scores from the wire and cannot see the audit trail, the metric or the ledger.
Driven by hand against the same stack, one turn of `[[f-malformed-json]]`
(`raw_arguments='{"text": }'`, the only document that actually reaches `invalid_tool_calls`):

```
tool_call    {"tool": "find_notes", "arguments": "{\"__unparsed_arguments__\": \"'{\\\"text\\\": }'\"}"}
tool_failed  {"tool": "find_notes", "message": "UnparsedArguments: The arguments for this call were
              not valid JSON, so it did not run. What was received was '{\"text\": }'. …"}
error        "The turn ended without producing an answer: 1 tool call(s) attempted, 1 failed. …
              The failure(s) reported above are the place to start"
```

No `tool_result` — the refusal pairs with the failure by the model's own call id and is suppressed,
so the sentence does not join the grounding corpus `score_answer` reads.

```
AUDIT      tool=find_notes outcome=error args={'__unparsed_arguments__': '\'{"text": }\''}
           detail=UnparsedArguments('The arguments for this call were not valid JSON, …')
turn_costs outcome=empty_answer tool_calls=1 tool_failures=1 tool_refusals=0
/metrics   chemclaw_invalid_tool_calls_total{tool="find_notes"} 2
```

**Every record the four earlier designs could not produce is there**: the audit row under the
`error` outcome, the failure on the wire with a real id, the counter, and a turn ledger that says
one call was attempted and one failed. Compare the pre-change wire for the identical behaviour —
`error/empty_answer, "after 0 tool call(s) … a narrower or more specific question is the useful
next step"`, with no `tool_call` and no `tool_failed` at all.

**One consequence worth stating rather than discovering.** The `tool_call` event carries the
sentinel key, so a surface renders the arguments as `{"__unparsed_arguments__": "'{\"text\": }'"}`.
That is the honest record — it is what the model sent — and the `tool_failed` immediately beneath it
is the readable half. Hiding it would make the event read as a call with no arguments, which is a
different and worse untruth.

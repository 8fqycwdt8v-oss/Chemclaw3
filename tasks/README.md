# `tasks/` — working memory between sessions

- **`todo.md`** — the current task's plan as checkable items, and its review when it closes.
- **`lessons.md`** — ≤30 rules learned from corrections; read at session start.

Nothing else lives here: audits, reviews and live-test notes stay in git history. What outlives a task
belongs in `docs/decisions/` (why) or `docs/planning/BACKLOG.md` (what is open or deferred).
